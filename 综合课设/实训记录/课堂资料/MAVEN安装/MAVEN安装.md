# 								MAVEN安装

1. 需要将MAVEN 的解压包解压到 D:/ 根目录下

2. 将 repository 解压包解压到 D:/ 根目录下

3. 打开 MAVEN 文件夹，找到 conf 文件夹打开。

   ![image-20240624092536713](image-20240624092536713.png)

4. 找到 setting.xml 文件。使用记事本打开即可。

   ![image-20240624092607305](image-20240624092607305.png)

5. 修改对应位置的本地仓

   ![image-20240624092807196](image-20240624092807196.png)

6. 粘贴镜像路径

   ![image-20240624093126166](image-20240624093126166.png)

7. 开打配置环境变量

   ![image-20240624093620820](image-20240624093620820.png)

8. 打开 path 。添加环境变量

   ![image-20240624093701924](image-20240624093701924.png)

9. 检测是否安装成功。

   1. 开打控制台 WINDOW+R  输入 CMD

      ![image-20240624093812646](image-20240624093812646.png)

   2. 出现 3.6.1 的本版号即可。

10. 在 IDEA 中配置 MAVEN

    ![image-20240624094033430](image-20240624094033430.png)

11. 找到 Build 进行自动更新设置

    ![image-20240624094123043](image-20240624094123043.png)

12. MAVEN 配置路径。

    ![image-20240624094206117](image-20240624094206117.png)

    ![image-20240624094226978](image-20240624094226978.png)
