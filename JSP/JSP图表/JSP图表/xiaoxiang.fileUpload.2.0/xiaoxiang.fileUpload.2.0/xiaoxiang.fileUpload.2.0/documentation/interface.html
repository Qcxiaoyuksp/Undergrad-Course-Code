<·> xiaoxiang.fileUpload.upBean:
  • upBean
    类构造器。
    • 语法：.upBean()
    • 返回:xiaoxiang.fileUpload..upBean的一个实例
    • 例子：
      命令行：xiaoxiang.fileUPload.upBean myUpbean=new xiaoxiang.fileUPload.upBean();
      javabean:<jsp:useBean id="myUpload" scope="page" class="xiaoxiang.fileUpload.upBean" />
  • getFiles
    返回本组件自定义的files类,此类包含了所有上传文件的文件数据。
    • 语法：.getFiles()
    • 返回:xiaoxiang.fileUpload.files的一个实例
    • 例子：xiaoxiang.fileUPload.files myfiles=myUpload.getFiles();
  • getRealPath
    得到文件保存的默认路径。
    • 语法：.getRealPath()
    • 返回：String
    • 例子：String realPath=myUpload.getRealPath();
  • getRequest
    返回本组件自定义的Request类
    • 语法：.getRequest()
    • 返回:xiaoxiang.fileUpload.Request
    • 例子：out.print(myUpload.getRequest().getParameter("fileName"));
  • initialize
    初始化Bean
    • 语法：.initialize(pageContext)
    • 没有返回值
    • 例子：myUpBean.initialize(pageContext);
  • setAllowedExtList
    设置允许上传的文件后缀名
    • 语法：.setAllowedExtList(String)
    • 没有返回值
    • 例子：myUpload.setAllowedExtList("gif,jpg");
  • setAllowedFileTypeList
    设置允许上传的文件类型
    • 语法：.setAllowedFileTypeList(String)
    • 没有返回值
    • 例子：myUpload.setAllowedFileTypeList("gif,pjpeg");
    • 常用的文件类型：
      • Gif格式图片:gif
      • jpg格式文件:pjpeg
      • word文件:msword
      • html文件:html
      • txt文件:plain
      更详细的表:reference_fileType.asp
  • setIsCover
    设置上传文件时是否覆盖服务器上的同名文件
    • 语法：.setIsCover(boolean)
    • 没有返回值
    • 例子：myUpload.setIsCover(false);
  • setMaxFileSize
    设置每次上传的文件中最大的文件的大小
    • 语法：.setMaxFileSize(int)
    • 没有返回值
    • 例子：myUpload.setMaxFileSize(100000);
  • setRealPath
    设定文件保存的默认路径。
    • 语法：.setRealPath(String)
    • 没有返回值
    • 例子：myUpload.setRealPath(application.getRealPath(File.separator+"fileUpload"));
  • setTotalMaxFileSize
    设置每次允许上传的所有文件的大小
    • 语法：.setTotalMaxFileSize(int)
    • 没有返回值
    • 例子：myUpload.setTotalMaxFileSize(1000000);
  • upload
    将文件和其他页面参数上传到服务器，并将数据存入特定的数据结构。
    • 语法：.upload()
    • 没有返回值
    • 例子：myUpload.upload();
